Ein Multiplayer-UNO-Kartenspiel, portiert von einem eigenständigen 
Express/MongoDB-Projekt zu einer statischen Seite mit Supabase Realtime.

## Was ich gelernt habe

- Portierung einer serverseitigen Game-Engine zu reinen Client-Side-Funktionen
- Immutable State-Management für Echtzeit-Multiplayer-Synchronisation
- Supabase Realtime fuer Game-State-Broadcasting
- Unterstützung von N-Spieler-Räumen (2-4 Spieler) mit flexiblem Lobby-System

## Technische Details

Die UNO-Game-Engine läuft vollständig im Browser als reine Funktionen — jede Aktion
(Karte werfen, ziehen, UNO ankündigen) nimmt den aktuellen State und gibt einen neuen
State zurueck. Dieser State wird in Supabase als JSON gespeichert und per Realtime-Subscriptions
an alle Spieler übertragen.

Features umfassen alle Standard-UNO-Regeln: Farb- und Zahlenmatching, Aussetzen, Richtungswechsel,
2 Ziehen, Farbwahl, 4 Ziehen, UNO-Ankündigung und Challenge-Mechanik.
