Eine React-Web-App zum Erstellen von thematischen Geburtstagseinladungen für Kinder.

## Features

- `Themenauswahl:` 8 Partymottos (Einhorn, Spider-Man, Dino, Prinzessin,
Meerjungfrau, Fussball, Feenwald, LEGO), die die gesamte UI verändern
- `KI-Ideen:` Claude generiert Slogan, Einladungstext, Deko-,
Aktivitäts-, Essens- und Dresscode-Vorschläge
- `Bearbeitbare Bereiche:` Jeder KI-generierte Text kann vor
dem Finalisieren per Klick überschrieben werden
- `Gästeliste:` Gäste mit Telefonnummern hinzufügen,
damit RSVPs zugeordnet werden können
- `Teilbarer Link + QR-Code:` Die Einladung speichern, um eine eindeutige
URL und einen herunterladbaren QR-Code zu erhalten
- `RSVP per Telefon:` Gäste öffnen den Link, geben ihre Telefonnummer
ein und antworten mit zugesagt / abgesagt / vielleicht
- `Druckversion:` Für A5 optimiertes Drucklayout mit QR-Code,
bereit zum Falten oder Versenden
- `Passwortschutz:` Nur die organisierende Person hat Zugriff
auf den Wizard; Gastlinks umgehen die Anmeldung

## Technishe Details

Dies ist ein Full-Stack-Lernprojekt mit
Next.js 16 App Router, serverseitige API-Routen, Supabase Postgres Datenbank,
Anthropic-Claude-API, QR-Code-Generierung, Cookie-basierte Authentifizierung
und Print-CSS.
Die gesamte UI ist auf Deutsch, und die App ist passwortgeschützt - nur
die organisierende Person kann Einladungen erstellen.
Die Einladungslinks für Gäste sind jedoch
öffentlich zugänglich.
