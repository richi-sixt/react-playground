Eine persönliche Portfolio- und Lebenslauf-Website zur Präsentation von Berufserfahrung, Ausbildung und Projekten.

## Features

- Responsives Design mit Dark-Mode-Unterstützung
- MDX-basierter Inhalt für Projekte, Berufserfahrung und Ausbildung
- Statischer Export für schnelles Hosting auf jeder Plattform
- Übersicht der Skills und Tech-Stack mit kategorisierten Karten

## Technische Details

Erstellt mit dem Next.js App Router und statisch exportiert. Der Inhalt wird in MDX-Dateien verfasst, die über ein privates Git-Submodul verwaltet werden. So bleibt das öffentliche Repository sauber, während persönliche Inhalte separat gepflegt werden. Die Website nutzt Tailwind CSS für das Styling und next-themes für den Dark Mode.
