Eine React-Plattform zum Lernen, Dokumentieren und praktischen Erkunden von React-Features, Patterns und Konzepten.

## Features

- Dokumentation der eigenen Lernreise und Experimentieren mit interaktiven MDX-Dateien
- Erstellung kleiner, in sich geschlossener Apps
- Verknüpfung von Journal-Einträgen mit Apps

## Technische Details

Erstellt mit dem Next.js App Router und statisch exportiert.
Die Inhalte werden in MDX-Dateien verfasst, die über ein privates Git-Submodul verwaltet werden. Dadurch bleibt das öffentliche Repository sauber, während persönliche Inhalte getrennt gehalten werden.
Für das Styling wird Tailwind CSS verwendet, und next-themes sorgt für den Dark Mode.
Multiplayer-Spiele (Räume) werden mit Supabase umgesetzt.
