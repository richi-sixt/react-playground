A web application for tracking calisthenics workouts and progressions, built with Python and Flask.

## Features

- Track exercises and progressions over time
- Log workout sessions with sets and reps
- View progress history and statistics
- Responsive design with Bootstrap

## Technical details

Built with Flask as the backend framework, using Bootstrap for the frontend styling. The application allows users to define their own exercise progressions and track their journey through bodyweight fitness levels.
